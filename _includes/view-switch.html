{%- comment -%} View switcher, shared by all three presentations of the site. One include, three consumers, so the set of modes lives in exactly one place: add a fourth mode here and every page gains it. The retro page cannot use this (it loads no site CSS by design), so it hand-rolls its own period-styled version and this file stays the source of truth for the modern + terminal pair. `mode` is passed in by the caller: 'modern', 'terminal' or 'retro'. The current mode renders as a non-link so you cannot click to where you already are. {%- endcomment -%} {%- assign mode = include.mode | default: 'modern' -%}
